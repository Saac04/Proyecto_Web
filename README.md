# Proyecto Web: PROA
 
 “Ayudamos a instituciones educativas a gestionar sus contenidos a través de módulos intuitivos y fáciles de usar que garantizan una conexión efectiva entre docentes y alumnos.” 

 Descripción del proyecto y objetivos (brief):
GTI, una empresa emergente de productos educativos quiere empezar a comercializar su primer producto, PROA, una interfaz de gestión interna para instituciones educativas. La empresa no consta de una plataforma para presentar su producto ni tiene un diseño definido. El objetivo es definir una guía de estilos y crear una página web para promocionar el producto y ofrecer una demo de PROA antes de junio del 2025. Para lograrlo, se desarrollará un sitio web moderno y accesible, con una identidad visual clara. Se priorizará la experiencia de usuario y la navegación intuitiva. La demo del PROA permitirá que las instituciones educativas conozcan sus funciones básicas antes de adquirirlo. La estrategia de desarrollo seguirá un enfoque ágil basado en sprints para garantizar avances progresivos y cumplir con los plazos establecidos.
